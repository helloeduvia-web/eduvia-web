# Eduvia — Student Platform

Eduvia is a student-first study-abroad discovery and planning experience for students across India.

## Included
- Eduvia branding with the tagline **Delivering Opportunities**
- Student-only navigation and dashboard
- Student login with email/password or mobile OTP
- Practical free assessment covering education stage, career direction, realistic budget, English readiness and preferred region
- Free profile snapshot with clear next actions
- Destination discovery
- General intake explorer for multiple planning years and countries
- Student roadmap, shortlist, documents, applications and counselling workspace
- Distinct HD imagery used once per website section/page to avoid repetition

## Run

```bash
npm install
npm run dev
```

The Vite frontend runs on the default Vite port and the Express API runs on port 4000.
